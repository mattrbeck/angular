# Ambiguous Pipe Function Call

This warning occurs when an expression in your template invokes a function that has the same name as both an in-scope pipe and a member of your component class.

## Why this happens

When using functional pipe syntax (such as `format(value)`), Angular searches the component's imports and declarations for a matching pipe. If your component class also defines a method or property named `format`, the template parser identifies this call as ambiguous.

By default, Angular resolves the identifier to the imported pipe.

## Debugging and fixing the warning

To resolve the ambiguity:

1. **If you intended to call the component method:**
   Add `this.` to explicitly target the component instance:

   ```angular-html
   <!-- Calls the component class method -->
   <div>{{ this.format(value) }}</div>
   ```

2. **If you intended to invoke the pipe:**
   Rename the conflicting component class member to avoid naming clashes with the pipe:

   ```typescript
   // Before: Conflicted with FormatPipe
   format(val: string) { ... }

   // After: Clear distinction
   formatCustom(val: string) { ... }
   ```

3. **Using automated migration:**
   You can run the automated migration schematic to resolve collisions across your project:
   ```bash
   ng generate @angular/core:pipe-function-calls
   ```
